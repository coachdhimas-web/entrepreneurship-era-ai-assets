## PANDUAN PENGGUNAAN

Kerjakan checklist ini secara jujur untuk mengukur kesiapan Anda dalam perjalanan Go Global. Setiap pertanyaan bernilai 1 poin jika menjawab "Ya" dan 0 poin jika menjawab "Tidak" atau "Tidak Tahu".

**Total Skor Maksimum: 25 poin**

## ASPEK A: KESIAPAN PRODUK EKSPOR (5 Poin)

### A1. Minat Pasar Global
```
Apakah produk Anda telah terbukti mendapatkan minat dari pasar global?
(Contoh: sudah ada 3+ pihak buyer global yang meminta sampel/penawaran)

□ Ya (1 poin)          □ Tidak (0 poin)          □ Tidak Tahu (0 poin)
```

### A2. Kemasan & Labelling Internasional
```
Apakah produk Anda bisa dikirim jarak jauh dan sudah memiliki kemasan, 
labelling, dan materi promosi standar internasional?
(Contoh: informasi dalam bahasa Inggris, ada nutrition facts, barcode)

□ Ya (1 poin)          □ Tidak (0 poin)          □ Tidak Tahu (0 poin)
```

### A3. Kapasitas Scale-Up
```
Jika produk Anda tiba-tiba mendapatkan permintaan ekspor skala besar 
(10x lipat dari produksi saat ini), bisakah bisnis Anda memenuhi?

□ Ya (1 poin)          □ Tidak (0 poin)          □ Tidak Tahu (0 poin)
```

### A4. Sertifikasi Dasar Nasional
```
Apakah produk ekspor Anda sudah memiliki sertifikasi dasar nasional?
(Contoh: Sertifikat Halal, PIRT, BPOM, Ekolabel)

□ Ya (1 poin)          □ Tidak (0 poin)          □ Tidak Tahu (0 poin)
```

### A5. Sertifikasi Internasional
```
Apakah produk ekspor Anda sudah memiliki standar internasional?
(Contoh: HACCP, ISO, FSC untuk kayu)

□ Ya (1 poin)          □ Tidak (0 poin)          □ Tidak Tahu (0 poin)
```

## INTERPRETASI HASIL

### Skor 19-25: SIAP GO GLOBAL 🎉

```
Selamat! Bisnis Anda sudah memiliki pondasi yang kuat untuk memulai 
atau meningkatkan aktivitas ekspor.

REKOMENDASI:
□ Fokus pada penguatan organisasi untuk pelaksanaan ekspor
□ Mulai Langkah 7-9 dalam Framework Go Global
□ Aktif mencari buyer dan participate dalam trade show
□ Persiapkan financing untuk scale up

NEXT STEPS:
1. Submit proposal ke buyer potensial
2. Prepare sample untuk showcase
3. Join komunitas export untuk networking
```

### Skor 10-18: POTENSIAL - BUTUH PERSIAPAN ⚡

```
Bisnis Anda memiliki potensi yang baik, namun masih perlu persiapan 
di beberapa area sebelum siap ekspor optimal.

REKOMENDASI:
□ Identifikasi area weakest dalam assessment ini
□ Mulai dari Langkah 4-5 dalam Framework Go Global
□ Fokus pada peningkatan pemasaran dan pemahaman financing
□ Ikut program pendampingan export

NEXT STEPS:
1. Buat improvement plan untuk area weaknesses
2. Education tentang regulatory compliance
3. Build network dengan support ecosystem
```

### Skor 0-9: BELUM SIAP - FOKUS FUNDAMENTAL 📚

```
Bisnis Anda perlu penguatan fundamental sebelum siap untuk ekspor. 
Jangan berkecil hati - semua bisnis successful memulai dari sini!

REKOMENDASI:
□ Mulai dari dasar dengan Langkah 1-3 dalam Framework Go Global
□ Fokus pada penguatan produk (standar 5K)
□ Persiapan legalitas dan organisasi
□ Ikut pelatihan dan pendampingan

NEXT STEPS:
1. Completing legalitas usaha
2. Ensure consistent product quality (5K)
3. Create basic marketing materials
4. Join local business community
```
