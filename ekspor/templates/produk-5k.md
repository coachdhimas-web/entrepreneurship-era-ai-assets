## PANDUAN PENGGUNAAN

Checklist ini membantu Anda mengevaluasi kesiapan produk berdasarkan standar 5K (Kualitas, Kuantitas, Kapasitas, Kontinuitas, Kemasan). Gunakan checklist ini secara berkala untuk track progress dan mengidentifikasi area yang perlu improvement.

---

## 1. KUALITAS (Quality)

> *"Apakah produk Anda sesuai dengan standar, tren, dan selera pasar global?"*

### 1.1 Aspek Visual & Fisik
```
□ Desain produk menarik dan mengikuti tren global
□ Finishing rapi dan professional
□ Detail teknis (jahitan, sambungan, dll) berkualitas
□ Tidak ada cacat fisik yang visible
□ Konsisten dengan sample yang dipromosikan
```

### 1.2 Aspek Fungsional
```
□ Produk berfungsi sesuai dengan deskripsi
□ Durabilitas sesuai ekspektasi
□ Packaging melindungi produk dengan baik
□ Shelf life mencukupi untuk distribusi internasional
□ Safe untuk digunakan/dikonsumsi
```

### 1.3 Aspek Sensori (untuk produk pangan)
```
□ Citarasa konsisten dengan brand standard
□ Aroma sesuai dengan karakteristik produk
□ Tekstur sesuai ekspektasi
□ Warna menarik dan appealing
□ Tidak ada rasa/aroma yang off
```

### 1.4 Aspek Laboratorium
```
□ Uji lab sesuai standar NTE (jika applicable)
□ Tidak mengandung kontaminan exceed limit
□ Residu pestisida di bawah threshold
□ Heavy metal content safe
□ Mikrobologi memenuhi standar
```

### 1.5 Dokumentasi Kualitas
```
□ Certificate of Analysis (CoA) tersedia
□ Quality inspection report per batch
□ Traceability dokumentasi
□ SOP quality control terdokumentasi
□ Customer complaint handling procedure
```

**Progress Kualitas:** □ Perlu Perbaikan  □ Berkembang  □ Baik  □ Sangat Baik

---

## 2. KUANTITAS (Quantity)

> *"Apakah jumlah stock yang siap tersedia sudah optimal?"*

### 2.1 Penentuan MOQ (Minimum Order Quantity)
```
□ MOQ per SKU sudah ditetapkan
□ MOQ realistic dengan kapasitas
□ MOQ attractive untuk buyer
□ MOQ memperhitungkan efisiensi produksi
□ MOQ memperhitungkan profit margin
```

### 2.2 Penentuan Max Order Quantity
```
□ Max order per siklus sudah diketahui
□ Max order realistic dengan capacity
□ Buyer diinformasi tentang max capability
□ Proses scale-up jika needed sudah planned
```

### 2.3 Efisiensi Produksi
```
□ Economies of scale sudah dihitung
□ Batch size optimal untuk efficiency
□ Setup cost sudah diperhitungkan
□ Waste minimization planned
□ Price competitiveness terjaga
```

**Progress Kuantitas:** □ Perlu Perbaikan  □ Berkembang  □ Baik  □ Sangat Baik

---

## 3. KAPASITAS PRODUKSI (Production Capacity)

> *"Apakah sistem produksi mampu memenuhi lonjakan order?"*

### 3.1 Fasilitas & Infrastruktur
```
□ Tempat produksi adequate size
□ Layout efficient dan ergonomis
□ Utilitas memadai (listrik, air, ventilasi)
□ Storage area terpisah (bahan baku & finished goods)
□ Compliance dengan regulasi K3 (Kesehatan & Keselamatan Kerja)
```

### 3.2 Mesin & Peralatan
```
□ Mesin sesuai dengan kapasitas yang dibutuhkan
□ Maintenance schedule teratur
□ Backup equipment tersedia (jika critical)
□ Technology updated sesuai industry standard
□ Calibration记录 (jika applicable)
```

### 3.3 SDM (Sumber Daya Manusia)
```
□ Jumlah worker cukup untuk scale up
□ Skill worker sesuai dengan requirement
□ Training program tersedia
□ Worker motivation & welfare maintained
□ Key person succession planned
```

### 3.4 SOP & Documentation
```
□ SOP produksi terdokumentasi
□ Work instruction jelas untuk setiap process
□ Quality control procedure standardized
□ Change management process exist
□ Documentation system organized
```

### 3.5 Scale-Up Capability
```
□ Can 10x current production if needed?
□ Lead time untuk scale up understood
□ Additional resource plan exists
□ Cost implication of scale up calculated
□ Risk of scale up identified
```

**Progress Kapasitas:** □ Perlu Perbaikan  □ Berkembang  □ Baik  □ Sangat Baik

---

## 4. KONTINUITAS (Continuity)

> *"Apakah ketersediaan bahan baku dan produksi terjamin secara berkelanjutan?"*

### 4.1 Sumber Bahan Baku
```
□ Primary supplier sudah established
□ Backup supplier identified
□ Alternative materials researched
□ Local vs import sourcing optimized
□ Supplier relationship good
```

### 4.2 Ketersediaan Material
```
□ Stock bahan baku aman untuk minimum 2-3 cycles
□ Seasonal availability accounted
□ Forward purchasing plan exists
□ Buffer stock policy defined
□ Material quality consistency maintained
```

### 4.3 Finansial
```
□ Budget for material procurement allocated
□ Cash flow can support continuous production
□ Payment terms with supplier negotiated
□ Working capital adequate
□ Financing backup plan exists
```

### 4.4 Risiko Management
```
□ Risk of supply disruption identified
□ Mitigation plan for each risk
□ Insurance coverage evaluated
□ Business continuity plan exist
□ Crisis management procedure defined
```

### 4.5 Sustainability
```
□ Sustainable sourcing considered
□ Environmental compliance met
□ Social responsibility addressed
□ Long-term supplier relationship valued
□ Circular economy opportunity explored
```

**Progress Kontinuitas:** □ Perlu Perbaikan  □ Berkembang  □ Baik  □ Sangat Baik

---

## 5. KEMASAN (Packaging & Labelling)

> *"Apakah kemasan dan labelling sudah sesuai standar internasional?"*

### 5.1 Packaging Design
```
□ Desain kemasan menarik untuk pasar target
□ Material kemasan sesuai dengan produk
□ Proteksi produk during shipping adequate
□ Size/volume sesuai dengan market preference
□ Eco-friendly option considered
```

### 5.2 Packaging Functionality
```
□ Mudah opened by consumers
□ Resealable if applicable
□ Stackable for retail display
□ Dimension efficient for shipping
□ Material weight optimized
```

### 5.3 Labelling Content
```
□ Product name & brand clear
□ Ingredients/composition listed
□ Net weight/volume stated
□ Country of origin indicated
□ Batch/lot number traceable
```

### 5.4 Labelling Compliance
```
□ Nutrition facts (pangan) sesuai format NTE
□ allergen information stated
□ Storage instruction clear
□ Preparation/use instruction included
□ Expiry date clearly printed
```

### 5.5 Labelling Language
```
□ Language sesuai dengan NTE
□ Bahasa当地 available (jika required)
□ Claims substantiated
□ Regulatory compliance met
□ Barcode/QR code functional
```

### 5.6 Certification Marks
```
□ Halal logo (if applicable)
□ Organic certification (if applicable)
□ Quality certification marks
□ Eco/sustainability marks
□ Import requirements met
```

### 5.7 Inner & Outer Packaging
```
□ Primary packaging (bersentuhan langsung dengan produk)
□ Secondary packaging (perlindungan tambahan)
□ Tertiary packaging (untuk distribusi - master carton)
□ Marking & labeling sesuai shipping requirement
□ Palletization plan exist
```

**Progress Kemasan:** □ Perlu Perbaikan  □ Berkembang  □ Baik  □ Sangat Baik
